# Rebate-Share demo

Offline single-file demo of the Rebate-Share (trading3) weekly network pool.

Open **https://v1cl00.github.io/trading3-demo/** (or `index.html` / `trading3-demo.html` locally). No server, no login passwords — pick a role.

Example data only (8.90 lots / 92.67 $ rebate). Commissions are USD per lot (network 13 $: L1 5.00, L2 2.50, L3 1.50, L4 1.00, L5–L10 0.50). The safety cap is an admin toggle and defaults to off.
